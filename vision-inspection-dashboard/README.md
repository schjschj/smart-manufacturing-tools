# 👁️ 제조업 검사 비전 방식별 (2D / 2.5D / 3D / AI) 비교 대시보드

> **제조 현장 비전 검사 도입을 위한 4대 핵심 기술 심층 비교, 레이더 차트 분석 및 투자 회수(ROI) 시뮬레이터**  
> 🔗 **배포 데모 (Live)**: [https://magical-narwhal-ae37fe.netlify.app/](https://magical-narwhal-ae37fe.netlify.app/)

---

## 📌 주요 기능

- **4대 머신비전 검사 기술 심층 비교**:
  - **2D 비전**: 전통적 에리어/라인스캔 기반 치수 및 유무 검사
  - **2.5D 비전 (Photometric Stereo)**: 다각 조명 합성 기반 표면 텍스처/음영 분리 검사
  - **3D 비전**: 광삼각법 및 백색광 간섭계 기반 높이/단차/체적 3차원 형상 측정
  - **AI 딥러닝 비전**: 복합 비정형 결함(스크래치, 찍힘, 미성형) 딥러닝 신경망 분류
- **인터랙티브 레이더 및 바 차트 시각화**:
  - `Chart.js` 기반 5대 지표(검출력, 택트타임, 조명 민감도, 구축 비용, 셋업 난이도) 다차원 비교
- **결함 유형별 최적 솔루션 매트릭스**:
  - 미세 스크래치, 찍힘, 핀홀, 도장 불량, 단차 등 12가지 주요 결함별 적합 기술 추천
- **CAPEX / OPEX 기반 ROI 시뮬레이터**:
  - 초기 설비 도입비, 인건비 절감액, 불량 유출 방지 효과를 반영한 투자금 회수 기간 계산

---

- **Chart Engine**: `Chart.js` (v4.x)
- **Typography**: Google Fonts (Outfit, Noto Sans KR)
- **Deployment**: Netlify
